# Grill question flow

Use this at the start of **every** research run.

## Goal
Lock enough scope to avoid wasted search breadth, while keeping the grilling short.

## Format rules — non-negotiable
- Ask **one question at a time**, never bundle multiple questions.
- Every question **must** be a **numbered MCQ** with 3–5 lettered options.
- Always include a **"→ Recommended:"** line after the options stating which option you recommend and why (one sentence).
- If the user picks an option or types a partial answer, map it to the closest option, confirm, then move to the next question.
- Do **not** start searching until all lock conditions below are met.

### MCQ template
```
**Q<N>. <Question text>**

A. <option>
B. <option>
C. <option>
D. <other / specify>

→ Recommended: <letter> — <one-sentence rationale>
```

---

## Default question order

**Q1. What is the primary deliverable?**

A. Short answer / quick fact-check  
B. Decision memo (recommendation + supporting evidence)  
C. Market map or landscape overview  
D. Competitor matrix (side-by-side comparison)  
E. Exploratory brief (concept map + source map + gaps)  

→ Recommended: B — a decision memo forces a clear objective and keeps synthesis actionable.

---

**Q2. What research type best fits this task?**

A. Market (size, segments, demand signals, constraints)  
B. Competitor (direct / indirect / substitute players)  
C. Exploratory (orient to a new topic, surface contradictions)  
D. Simple-topic (answer a specific factual question)  

→ Recommended: infer from Q1 answer and state which fits best.

---

**Q3. What depth tier is appropriate?**

A. Quick — 3–5 queries, 5–10 pages, 1 expansion pass  
B. Standard — 6–10 queries, 10–20 pages, 2–3 expansion passes  
C. Deep — 10–20 queries, 20–40 pages, 3–5 expansion passes  
D. Let me infer from the task complexity  

→ Recommended: B (Standard) unless the user signals urgency or exhaustive coverage is required.

---

**Q4. What is the most important question this research must answer?**

A. <infer option 1 from the task>  
B. <infer option 2 from the task>  
C. <infer option 3 from the task>  
D. Something else — I'll specify  

→ Recommended: state which option you believe is the primary must-answer question.

---

**Q5. What geographic or temporal boundary applies?**

A. Global / no restriction  
B. Specific region (e.g. US, India, EU) — I'll specify  
C. Specific time window (e.g. last 12 months, 2023–2025)  
D. Region + time window combined  

→ Recommended: A unless the topic is clearly regional or time-sensitive.

---

**Q6. Which source classes are required?**

A. Official / primary sources only (company sites, regulatory, academic)  
B. Primary + independent secondary (news, analyst reports, reviews)  
C. All of the above + behavioral traces (job posts, pricing pages, forums)  
D. No constraint — use whatever provides best coverage  

→ Recommended: B for most tasks; C for competitor or market research.

---

**Q7. Is the scope manageable in a single run, or should it be decomposed?**

A. Single run — the scope is well-bounded  
B. Decompose into 2 branches — I'll run them sequentially  
C. Decompose into 3+ branches — recommend the first branch and pause  
D. Unsure — suggest a decomposition  

→ Recommended: A for standard tasks; C when the topic spans multiple distinct domains.

---

## Research-type-specific follow-up questions

Ask these **after** Q1–Q7, only for the relevant type.

### Market
**QM1. Which market dimension is most important?**

A. TAM / SAM / SOM sizing  
B. Demand signals and growth drivers  
C. Customer segments and personas  
D. Market constraints and barriers  

→ Recommended: A if the user needs to size the opportunity; B for go/no-go decisions.

---

**QM2. Which customer segment should be the primary focus?**

A. Enterprise / large organizations  
B. SMB / mid-market  
C. Consumer / individual users  
D. All segments — compare across  

→ Recommended: state which segment fits best given the stated objective.

---

### Competitor
**QC1. What competitive scope should be used?**

A. Direct competitors only (same product category)  
B. Direct + indirect competitors  
C. Direct + indirect + substitutes  
D. Named competitors only — I'll list them  

→ Recommended: B for most competitive analyses; C when disruption risk matters.

---

**QC2. Which competitive signals matter most?**

A. Pricing and packaging  
B. Product features and positioning  
C. GTM and distribution strategy  
D. All of the above  

→ Recommended: D for a full matrix; A or B when the decision is narrower.

---

### Exploratory
**QE1. What is the primary goal of this exploration?**

A. Concept mapping (understand the space and terminology)  
B. Source mapping (find the authoritative references)  
C. Gap finding (identify what is unknown or contested)  
D. All three — produce a full exploratory brief  

→ Recommended: D unless time is constrained.

---

**QE2. Should contradictions and minority views be surfaced prominently?**

A. Yes — surface all contradictions and note confidence levels  
B. Only if they affect the main conclusion  
C. No — focus on consensus view  

→ Recommended: A for exploratory work; it prevents false confidence.

---

### Simple-topic
**QS1. What confidence level is required for the answer?**

A. Best available evidence is sufficient  
B. Multiple independent sources required  
C. Primary / official source required  

→ Recommended: B for most factual questions.

---

**QS2. What output length is preferred?**

A. One sentence or bullet  
B. Short paragraph with key caveats  
C. Structured brief with sources  

→ Recommended: B unless the user asked for a quick fact-check.

---

## Stop grilling when
You can state all of the following clearly:
- objective
- research type
- tier
- must-answer questions
- major boundaries
- output shape

If still ambiguous after Q7, ask the narrowest next question — still in MCQ format.

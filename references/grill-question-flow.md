# Grill question flow

Use this at the start of **every** research run.

## Goal
Lock enough scope to avoid wasted search breadth, while keeping the grilling short.

## Default order
Ask one question at a time.

1. **What is the deliverable?**
   - short answer
   - decision memo
   - market map
   - competitor matrix
   - exploratory brief

2. **What research type is this?**
   - market
   - competitor
   - exploratory
   - simple-topic

3. **What depth tier fits?**
   - quick
   - standard
   - deep
   - if unspecified, infer and confirm

4. **What must be answered?**
   - list the non-negotiable questions

5. **What boundaries matter?**
   - geography
   - time horizon
   - customer segment
   - product category
   - exclusions

6. **What source classes are required?**
   - official / primary
   - independent / secondary
   - behavioral traces
   - directories / databases / reviews / forums if relevant

7. **Is the request too broad for one run?**
   - if yes, decompose into branches
   - recommend the first branch
   - confirm with the user before proceeding

## Research-type-specific prompts

### Market
Ask about:
- category definition
- segments/subsegments
- geography
- time horizon
- desired output: TAM/SAM/SOM, demand signals, constraints, competitor map

### Competitor
Ask about:
- direct vs indirect vs substitute scope
- named competitors if any
- pricing/product/positioning/reviews/hiring signals needed
- whether comparisons should emphasize strategy, features, pricing, or GTM

### Exploratory
Ask about:
- orientation vs conclusion
- whether the goal is concept mapping, source mapping, or gap finding
- whether contradictions should be surfaced prominently

### Simple-topic
Ask about:
- exact question to answer
- required confidence level
- whether a concise answer or short explain-it-to-me brief is wanted

## Stop grilling when
You can state all of these clearly:
- objective
- research type
- tier
- must-answer questions
- major boundaries
- output shape

If still ambiguous, ask the narrowest next question.

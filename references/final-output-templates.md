# Final output templates

Keep the chat response concise. Use the smallest template that still serves the task.

## Universal concise template
```md
## Answer
[1-4 short paragraphs]

## Key evidence
- [claim] — [source]
- [claim] — [source]
- [claim] — [source]

## Caveats
- [gap, contradiction, or limitation]
- [optional next step]

## Raw artifact
Saved to: `path-or-obsidian-link`
```
